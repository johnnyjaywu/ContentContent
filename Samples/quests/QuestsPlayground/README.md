# Quests Playground Sample

Drop-in sample for `com.contentcontent.quests`.

## Usage

1. Select **ContentContent - Quests** in **Window -> Package Manager** (with `com.contentcontent.core` installed) and click **Download** under **Downloadable Samples** (installs into `Assets/Samples/ContentContent/Quests/QuestsPlayground/`).
2. Click **Open Scene** (or open `QuestsPlayground.unity`) and enter Play Mode.
