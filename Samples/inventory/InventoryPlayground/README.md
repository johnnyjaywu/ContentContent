# Inventory Playground Sample

Drop-in sample for `com.contentcontent.inventory`.

## Usage

1. Select **ContentContent - Inventory** in **Window -> Package Manager** (with `com.contentcontent.core` installed) and click **Download** under **Downloadable Samples** (installs into `Assets/Samples/ContentContent/Inventory/InventoryPlayground/`).
2. Click **Open Scene** (or open `InventoryPlayground.unity`) and enter Play Mode.
