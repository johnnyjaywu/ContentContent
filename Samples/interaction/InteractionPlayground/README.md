# Interaction Playground Sample

Drop-in sample for `com.contentcontent.interaction`.

## Usage

1. Select **ContentContent - Interaction** in **Window -> Package Manager** (with `com.contentcontent.core` installed) and click **Download** under **Downloadable Samples** (installs into `Assets/Samples/ContentContent/Interaction/InteractionPlayground/`).
2. Click **Open Scene** (or open `InteractionPlayground.unity`) and enter Play Mode.
