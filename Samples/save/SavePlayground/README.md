# Save Playground Sample

Drop-in sample for `com.contentcontent.save`.

## Usage

1. Select **ContentContent - Save** in **Window -> Package Manager** (with `com.contentcontent.core` installed) and click **Download** under **Downloadable Samples** (installs into `Assets/Samples/ContentContent/Save/SavePlayground/`).
2. Click **Open Scene** (or open `SavePlayground.unity`) and enter Play Mode.
