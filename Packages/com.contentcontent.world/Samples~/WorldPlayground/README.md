# World Playground Sample

Drop-in sample for `com.contentcontent.world` using Unity's New Input System (`com.unity.inputsystem`).

## Usage

1. Import this sample from **Window -> Package Manager -> ContentContent - World -> Samples**.
2. Attach `WorldPlaygroundSample` to an empty GameObject and enter Play Mode.
3. Navigate rooms, toggle ability gates (`WallJump`), compare safe-ground hazard recovery (preserves defeated enemy state) vs. bench death respawn (resets room enemies), and view live `WorldReachabilityValidator` results.
